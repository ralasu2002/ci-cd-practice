#Add calculator function

When asked to add a new function to the calculator:

a) create a new branch named feature/<function-name>
b) add the function to calculator.py following the existing style (simple, pure functions, no side effects)
c) add a matching test in test_calculator.py including atleast one edge case (zero, negative number, or large number)
d) Run pytest locally and fix the failures before proceeding
e) Commit with clear message describing the function added
f) Push the branch to the GitHub
g) Open a pull request from the branch into main.
