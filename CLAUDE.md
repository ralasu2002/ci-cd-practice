# Project Rules

1. All new functions in `calculator.py` must have a matching test in `test_calculator.py`.
2. Always run `pytest` locally before saying the task is complete.
3. Never commit directly to `main` — always create a branch first.
4. Keep functions pure and small (no side effects, no `print` statements inside `calculator.py`).
5. Before modifying `.github/workflows/*.yml`, stop and ask for explicit confirmation.
